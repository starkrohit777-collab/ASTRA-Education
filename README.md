# ⚡ ASTRA — Learn. Equip. Conquer.

> **A modern cinematic educational platform built for students who want to learn, practice, and level up.**

ASTRA is a modern **React-based educational platform** designed to make learning more engaging through a cinematic, futuristic, and interactive experience.

Instead of treating education like a boring dashboard, ASTRA turns learning into a journey — **learn new concepts, complete missions, test your knowledge, and keep progressing.**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/starkrohit777-collab/ASTRA-Education.git
```

Navigate into the project:

```bash
cd ASTRA-Education
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite.

---

## 🧑‍💻 Development

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
